# EcoFusion

Учебный прототип системы обработки сообщений ВКонтакте
о возможных местах несанкционированного размещения отходов.

Проект разработан в рамках выпускной квалификационной работы
по программе «Инженер данных (продвинутый)».

## Назначение

EcoFusion обрабатывает текстовые публикации ВКонтакте,
выделяет географические признаки, выполняет поиск
Яндекс Панорам и предварительный анализ изображений
с помощью YOLO11n.

Обнаружение объекта моделью не является подтверждением
незаконного размещения отходов. Окончательное решение
принимает аналитик.

## YOLO11n

Рабочая модель: ecofusion_yolo11n_best.pt

Параметры:
- confidence: 0.50
- imgsz: 1280
- classes: dump, rubbish
- device: CPU

Обученные веса модели не размещаются в репозитории.

## Ограничения

Модель YOLO11n может пропускать скопления отходов
или ошибочно распознавать другие объекты.

В частности, в контрольном примере публикации 5
крупная куча отходов на кандидате 38 не была
обнаружена моделью, но была зафиксирована
при ручном визуальном анализе.

Проект предназначен для учебной демонстрации.
Автоматическая юридическая оценка не выполняется.

## Запуск

Для запуска необходимы Docker Desktop,
PostgreSQL, SeaweedFS, локальные данные
и обученная модель YOLO11n.

Рабочий сценарий запуска анализа:

scripts/analyze_found_panoramas.ps1

Сценарий принимает параметр SearchRunId.
Анализ запускается вручную.

Пример для нового, ещё не обработанного запуска:

.\scripts\analyze_found_panoramas.ps1 -SearchRunId <ID>

Не запускайте повторную обработку исторических
результатов без предварительной проверки их состояния.
